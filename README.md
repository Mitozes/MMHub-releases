# MMHub releases

This repository holds the free MMHub installer for Windows. It contains no source code.

Download the latest `MMHub-Setup-<version>.exe` from the [Releases](https://github.com/Mitozes/MMHub-releases/releases) page and run it. Your library, playlists and settings are kept in `%APPDATA%\MMHub` and are never touched by installing, upgrading or uninstalling.

No release has been published here yet.
